# 玉米講鬼 剪輯 skill

把一段「只有聲音」的鬼故事，剪成玉米當主持人、會越看越毛的 16:9 影片。
第一集《黃皮子討封》(2026-11) 的完整工程檔在 `episodes/黃皮子討封/`，有問題先照那集抄。

## 0. 環境準備（每個新的雲端環境做一次）
```bash
apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra        # 繁體字幕/字卡字型
pip install opencv-python-headless scipy pypinyin faster-whisper fonttools brotli
```
- ffmpeg 需要有 libass / loudnorm（Ubuntu 套件版即可）。
- 網路要放行：`drive.usercontent.google.com`、`drive.google.com`（從 Drive 下載素材）、`videos.pexels.com`（圖庫 B-roll）。
- 語音辨識模型：faster-whisper `small` 的 CTranslate2 權重放在 `/tmp/wm/model`。Hugging Face 的檔案 CDN 若被擋，第一集是從 npm 套件 `@skillninja/shortmovie-telop-model-p0..p3` 拼回來的（權重檔，非程式碼；與官方 checksum 不同，辨識結果一定要人工校對）。

## 1. 素材
| 東西 | 位置 | 說明 |
|---|---|---|
| 玉米嘴型 | `assets/mascot/v_*.png` | closed/half/open/wide/o/frown/blink，512px。新造型用 `tools/make_mouth_sprites.py` 從 3×2 表情表產生 |
| 直播間 | `assets/studio/room.webp`、`desk.webp` | 背景 + 透明桌面前景層（麥克風在左） |
| 配樂 | `assets/music/horror_bgm.mp3` | vidIQ AI 生成的中式民俗恐怖配樂（免版稅）。0–70s 鋪陳、75s 起爬升、120–145s 最緊張 |
| 字型 | `fonts/` + 系統 Noto CJK | 字幕＝Noto Sans CJK TC Black；字卡/標題＝Noto Serif CJK TC Black 加破碎效果 |
| B-roll / 音效 | **不放 repo**，放使用者 Google Drive | 圖庫授權不可再散布；Pexels 需署名 |

**B-roll 來源優先順序**：使用者用 Gemini（Veo）生成的故事專屬鏡頭 > Vecteezy（使用者帳號）> Pexels（vidIQ `vidiq_find_broll`）。
需要使用者動手時，產生「給本機 Claude 的指令」讓他貼到本機 Claude in Chrome 執行。**一次列完整清單**（使用者要求一次做完），附優先順序，標明額度用完就停、不要付費。最新範本：`episodes/黃皮子討封/給本機Claude的完整素材生成指令.md`。

**同一個人物（重要）**：故事主角在所有鏡頭必須是同一張臉，否則會出戲。做法：
1. 從已有素材挑一個最符合故事的人物，截一張臉清楚的畫面當參考圖（第一集是 `episodes/黃皮子討封/REF_村民男子.png`：灰白亂髮、鬍渣、舊中式棉襖的中年村民），上傳到使用者的素材資料夾。
2. 指令要求兩步：先在 Gemini 上傳參考圖做「同一個人在某場景」的圖片（Nano Banana 能保持臉和衣服），確認像了再用該圖當起始畫面做影片（Veo）。
3. 影片額度用完時可只交圖片（.png）；引擎會把靜態圖用鏡頭推拉做成動態畫面。
4. 時代/場景要一致：不要柏油路、黃線、路燈、現代公園、棕櫚樹、登山鞋等現代物件。
本 skill 不可替使用者登入網站或繞過網站的防機器人驗證。

## 2. 流程
1. **下載音檔**（Drive → `a48.wav` 48k mono；`a16.wav` 16k 給辨識）。量 LUFS，原片常在 −19，成片目標 −14。
2. **逐字稿**：faster-whisper word timestamps → `transcript.json`。
3. **讀完整份逐字稿再決定剪法**（不要只看開頭）：
   - 冷開場：只放**一句**高潮裡鬼的台詞當鉤子（使用者覺得兩句就拖）→ 標題砸下。
   - 玉米開場只留打招呼 + 一句話講完傳說 + 「亂回答會怎樣」這類鉤子；**故事要在 1 分鐘內開始**（使用者明確要求：前面介紹不能長）。
   - 刪：更新時間/閒聊、重複的背景解說、「我怎麼找到這故事」。
   - 故事本體幾乎全留；結尾的笑點保留當鬆一口氣，再收結論、訂閱、拜拜。
   - **恐怖＋搞笑交錯（參考微疼【微鬼畫】）**：每集放 1–2 個玉米的吐槽/笑點，**放在大驚嚇的前面**——先讓觀眾鬆下來，下一拍硬切回黑暗，驚嚇更有力。原音沒有笑點時，從玉米的閒聊裡挑一句自嘲或吐槽（例：「叫動物園過來抓一下」）。笑點 block：`light` 0–0.1、`dread` ≤0.1、`music_db` 約 −8（配樂不斷）；下一個 block 用 `trans: flicker`/`flash` + `hit` 音效，`light` 直接跳到 0.9 以上。
   - 聽不清楚的句子不要亂猜；改用「停頓 + 燭火 + 心跳」接過去（第一集廟祝段落的做法）。
4. **剪接點對齊（使用者要求：沒說完就砍掉的要補回來）**：EDL 寫好後一定跑
   `python3 -I tools/snap_edges.py edl.json edl_snapped.json --report`，把每段的結尾延到真正安靜的地方（最多 +0.7 秒）、開頭退到聲音開始處。
   報告裡被延長 ≥0.5 秒的段落要逐一看：如果延進去的是故意刪掉的重複/口誤（例：「你的APP…你的APP」「5142…5124」）或半句話（「還是…」），手動改回，或改成保留前面、刪後面那個重複。改完時間軸會變，字幕與分鏡要用「原音時間」重新對到新時間軸（第二集 v2 的做法），不要重打字幕。
   連續兩個 host block（中間沒有 flicker/flash）時，後一個的 zoom 從前一個的結束值接著推，不要跳（`build_edl.py` 末段的 smooth host camera）。
4. **寫 EDL**（`build_full_edl.py` 範本）：每個 block = 一段旁白 + 模式（host/broll/black）+ `light`（0 暖 → 1 全黑）+ `dread`（配樂/環境音強度）+ 字卡 + 音效。`max_pause` 越恐怖留越長（0.35 → 1.3s）。
5. **字幕**：用剪好的旁白重新辨識一次（時間軸才會對齊成片），再**逐句人工校對成繁體**（`subs_v2.py` 範本，`|` 是斷行點，`None` = 故意不上字幕）。常見錯字見 EDL 的 `fixes`（英國→因果、秘密→玉米、黃蜀狼→黃鼠狼、討風→討封…）。
6. **逐句分鏡**（`shots_v3.py` 範本）：`[成片秒數, 想要的檔名 | None, 備用素材名 | "host"]`。「想要的檔名」會到 EDL 的 `vecteezy_dir` 找同名開頭的 .mp4（沒有才用 .png），找不到就用備用素材，所以可以先排好、使用者上傳後直接重算。規則：
   - 每句畫面要對到台詞內容；**對不上就回玉米主持畫面，不要硬塞**（使用者明確要求）。
   - 單一畫面最長 3 秒（引擎自動切）。
   - 每句畫面**從頭連續播完**：不切段跳來跳去、不鏡像翻轉、不循環（使用者明確不要「來回放」）。同一支素材用在相鄰幾句時接著往下播。
   - 素材不夠長就**放慢**（最慢 0.45×），放慢時用 minterpolate 動態補幀到 30fps，避免一頓一頓（實測純放慢 40% 是重複幀，補幀後 0%）。真的用完才重播，並用 `PLAN_DEBUG=1` 印出計畫檢查是否有 replay。
   - 完全相同的檔案要先合併成同一個名字（`cmp` 檢查）。
   - 使用者上傳的 Gemini 檔名常是 `gemini_generated_video_xxxx.mp4`：下載後抽 1/5/9 秒做對照表，自己認出是哪個 N 鏡頭，在 `vecteezy_dir` 用 symlink 命名（同一支可以 symlink 成兩個名字，例如來電畫面＋未接來電清單，用 `vstart` 指定不同起點）。
   - 分鏡時間錨在「那句字幕的開始」；若落在 block 開頭前 0.6 秒內，要對齊到 block 開頭，否則會變成 0.1 秒的閃鏡（第二集 v5 修過）。
   - 注意：`--stills` 抽圖時同一鏡頭只有第一張時間準確，檢查放慢/長鏡頭要用 `--range a,b` 真的算一小段。
7. **算圖**：
   ```bash
   python3 -I engine/ghost.py edl.json out.mp4 --video-only --stills 30,120,250   # 先抽幾張圖檢查
   python3 -I engine/ghost_parallel.py edl.json final.mp4 4                       # 4 段平行（7.5 分鐘片約 25 分鐘）
   python3 -I engine/ghost_parallel.py edl.json final.mp4 4 --reuse-video        # 只換音效/混音時，約 3 分鐘
   ```
   預覽版：`ffmpeg -i final.mp4 -c:v libx264 -b:v 3000k -c:a copy preview.mp4`。
   - 看完覺得長：`python3 -I engine/cut_edl.py edl.json edl_new.json subs_new.json 87.2-93.5 111.2-131.6 …`（成片時間區段），字幕與分鏡自動對齊新時間軸。第一集從 7:25 剪到 6:06，原則：人物反應/動機只講一次、道理只講一次、口誤重複刪掉。
8. **配樂音量檢查（使用者反映過「BGM 聽不到」）**：
   ```bash
   STEMS_DIR=stems python3 -I engine/ghost.py edl.json stems/mix.wav --audio-only   # 輸出 voice/music/bed_all 分軌
   ```
   逐分鐘量「配樂比人聲低幾 dB」（講話時，0.1s RMS 中位數）。目標：**整片 12–15 dB**，每分鐘差距不超過 3 dB；人聲一定最大，但配樂要一直聽得到、不能有斷掉的空白。
   - 引擎已對配樂做慢速自動音量（4 秒窗、70% 壓縮）＋ 2 秒跳段交叉淡化。EDL 的 `music_db` 一般 −4（高潮）～ −6，笑點/結尾也不要低於 −8（第一集原本 −30 幾乎無聲）。
   - `music_at` 跳段點要避開配樂本身的靜音處（`horror_bgm` 57–61s、90s 附近），用 `--audio-only` 量每秒 music 是否 < −45 dB。
   - 剪接點檢查：用 `transcript.json` 的字級時間，確認每個 piece 的頭尾沒有切在字中間（第一集 `cut_edl` 後留下半個「這男」，要再剪掉）。
9. **YouTube 章節**：用最終版字幕檔排章節，貼在說明欄（附在 `素材來源_影片說明用.txt` 最後）。
   - 規則：第一行 `00:00`、至少 3 段、**每段 ≥10 秒（含第一段！冷開場只有 7 秒時要併入開場）**、時間遞增。
   - 每個時間碼 = 該段第一句字幕的實際開始秒數（無條件捨去），不能為了湊規則改時間；用腳本逐段算長度驗證。
   - 6 分鐘片約 8–10 段，太密觀眾不好選。標題寫成鉤子不劇透（例：「黃鼠狼開口了」「第二天，他瘋了」）。
10. **交付前檢查**：抽 6–10 張圖；量 LUFS（−14 ±0.5，TP ≤ −1.5）；字卡/字幕是否被 duplicated 原文時間誤對（引擎已改成 block 內對時）。

## 3. 風格規格
- **畫面**：16:9 1920×1080 30fps。直播間：房間背景微模糊、玉米 1.2× 坐在桌後、桌子前景層；左上「玉米講鬼 TALK／民間怪談系列」標籤。
- **燈光隨恐怖程度**：`light` 0→1，房間變暗、去飽和、偏冷、加暗角；B-roll 統一冷色去飽和 + 膠片顆粒；`red` 素材加紅。
- **玉米**：中文拼音韻母決定嘴型（a 類大張、o/u 圓嘴、e/i 半張、b/p/m 先閉），靜音自動閉嘴，2–5 秒隨機眨眼，呼吸起伏。`light ≥ 0.4`（故事段）時不用笑臉嘴型：講話用「o」驚訝嘴、閉嘴用皺眉臉。B-roll 時縮進右下紅框圓形小窗繼續對嘴。
- **字卡**：鬼/怪物的台詞用破碎宋體，白字 + 血紅字（`#E82226` 帶紅光），出現時閃爍；host 畫面時放左側避開玉米的臉。
- **故事章節卡**：玉米開場結束、故事開始前插一張 2.6 秒的黑底白字卡（gap block 加 `chapter: {"kicker": "那天晚上", "text": "凌晨一點的那輛車"}`，`mode: black`、`pip: false`）。乾淨宋體、淡入淡出、輕輕一聲低音，不用破碎效果（跟恐怖標題做區隔）。**每集只放一張**（使用者想要；多了會打斷緊張感）。插入後要把之後的字幕/分鏡往後推 gap 秒數，跨過插入點的那句字幕結尾要截在插入點。
- **標題**：白字＋血紅副標＋做舊金色紙條，砸下時震動＋重擊。
- **字幕**：底部置中、白字黑邊、每句 ≤14 字，**永遠顯示**（字卡出現時也要顯示）。
- **強調字幕**：字幕檔裡用 `{}` 包住關鍵詞（例 `怎麼樣都{動不了}`），該詞變血紅、放大 1.2×、帶紅光，整句出現時放大彈入＋抖動 0.35 秒。**每集 4–6 處**，只給轉折/最可怕的詞（第一集：像齊天大聖、狂風大作、動不了、承受不起的因果、附身），用太多就沒感覺。
- **角色聲音**：鬼/怪物的台詞在 EDL block 加 `voice_fx`（`{"t": [a, b], "fx": "ghost"}`，block 內秒數；或 `"src": [a, b]` 原音秒數）。`ghost`＝降約 3 個半音＋多重回音＋悶一點；`old`＝老人；`whisper`＝氣音耳語。只改音高不改時間，對嘴與字幕不受影響。範圍用字幕時間抓整段台詞（第一集：黃鼠狼的每句問話與警告、被附身的「俺不是齊天大聖」）。玉米自己錄音時若能用不同口氣演角色更好，`voice_fx` 再疊上去。
- **轉場**：硬切為主；換場 fade；燈閃 flicker；狂風 flash。
- **嚇人的動態（使用者：「沒有很可怕，BGM 不明顯」）**：故事段配樂約在人聲下 7 dB（不是 12–15）；每個大驚嚇前一個 block 「暴風雨前的寧靜」：`music_db` −12～−16 + 心跳（實測人聲下 17–21 dB），驚嚇那個 block `music_db` 0 + hit + stinger（人聲下 5 dB）。`drone_db` −19。量的時候先高通 250 Hz（手機喇叭聽不到低頻）。
- **轉搞笑要「突然」**：笑點第一個 block 開頭 `scratch`（唱片刮）把恐怖配樂切掉（`music_db` −40），改用 `amb_comic`（彈跳喜劇 loop，約 −9）＋ 笑點 `boing`；回到恐怖時喜劇 loop 直接停，下一拍 `hit`。
- **聲音**：人聲高通+壓縮 → 配樂（鋪陳段用前段、恐怖段跳到爬升段，講話時自動壓低約 5 dB，整片穩定在人聲下 12–15 dB）→ 環境音床（蟲鳴/風/暴風/室內）→ 心跳（恐怖段）→ 一次性音效（低語、貓頭鷹、腳步、草叢、樹枝斷、重擊、吸氣聲、廟鐘、木魚）。最後兩段式 loudnorm −14 LUFS。真實音效檔透過 EDL 的 `sfx_files` / `bed_files` / `heartbeat_file` 指定，缺的會用 `engine/foley.py` 合成版。
- **節奏參考**：16 分鐘原音檔 → 約 6 分鐘成片（使用者看完 7.5 分鐘版覺得太長）；冷開場 0:00、玉米開場 0:12、故事 0:58、高潮 ~2:20。
- **不要用**：抽象的「一排排動物眼睛」素材（使用者覺得怪）。
- **桌子**：`assets/studio/desk.webp` 是使用者 2026-11 給的新版（單把手馬克杯，放在玉米前面是對的）。第一集嫌「杯子怪」是指舊圖的**雙把手**杯，不是位置；舊的去杯版留在 `desk_v1_nomug.webp`。

## 4. 已知限制
- 語音辨識錯字多（尤其馬來西亞口音、後段會跑成簡體），字幕必須人工校對。
- 玉米素材只有 512px，主持畫面放大後偏軟；有高解析度原圖要換掉 `assets/mascot`。
- 「狂風大作」那一下陣風仍是合成音效。
- EDL 範本裡的路徑是第一集當時的暫存路徑，換環境要改成新的位置。
